# SimNow 量化交易项目

## 什么是 SimNow？

SimNow 是由**上海期货信息技术有限公司（上期技术）**为投资者和开发者打造的**仿真交易平台**。它主要用于金融衍生品（期货、期权）的模拟交易。

### 核心特点：
1. **基于 CTP 架构**：SimNow 采用了与实盘完全一致的 **CTP (Comprehensive Transaction Platform)** 综合交易平台架构。这意味着在 SimNow 上开发的程序和策略，可以无缝切换到实盘环境。
2. **全品种支持**：支持上海期货交易所、郑州商品交易所、大连商品交易所、中国金融期货交易所等国内主流交易所的期货和期权品种。
3. **两套环境**：
    - **第一套（7x24）**：主要用于非交易时间的测试，行情可能是历史重放。
    - **第二套（与实盘同步）**：交易时间与实盘一致，行情也是实时的（模拟），适合模拟实盘压测。

### 为什么它很重要？
对于国内的量化交易开发者来说，**CTP 接口**是事实上的行业标准。SimNow 提供了最权威的 CTP 接口测试环境，是开发 Python (如 vn.py) 或 C++ 量化交易系统的必经之路。

## 项目目标
本项目旨在探索 SimNow 的接入与量化策略实现。
