# KovaaK's 灵敏度助手

本仓库包含有关 KovaaK's 练枪软件灵敏度设置的指南和工具。

## 内容

- [GUIDE.md](GUIDE.md): 详细说明如何在 KovaaK's 软件中找到并修改灵敏度设置，以匹配你玩的游戏。
- [sensitivity_converter.py](sensitivity_converter.py): 一个简单的 Python 脚本，用于在不同游戏（如 Overwatch, Valorant, CS:GO）之间转换灵敏度数值。

## 使用方法

1. 阅读 `GUIDE.md` 了解如何在软件中设置。
2. 如果需要转换灵敏度，可以在终端运行：
   ```bash
   python sensitivity_converter.py
   ```
